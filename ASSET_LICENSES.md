# FARMAN — Asset Licences and Provenance

Every asset shipped in `public/assets/` is either generated by this project or is a font
under the SIL Open Font License. No third-party model, texture, audio recording or
photograph is included. This file is the inventory; if an asset is added without an entry
here, the change is incomplete.

Verified 2026-11-12 by reading the generators in `tools/assetgen/` and the `license` field of
each installed package in `node_modules/`.

## 1. Procedurally generated assets (original, project-owned)

All of these are produced by Python scripts in `tools/assetgen/` from parametric code and
fixed seeds. They contain no sampled or traced third-party artwork. Copyright in the output
belongs to the project.

## 5. What is explicitly not included

- **No third-party 3D models.** Every `.glb` in `public/assets/` is written by
  `tools/assetgen/*.py` (custom writer in `glb.py`).
- **No third-party textures or photographs.** Every `.png` is generated by
  `tools/assetgen/textures.py` or `sky.py`, or rendered by Babylon at runtime
  (`DynamicTexture` for the fallback pad and studio floor pool).
- **No audio recordings, music, or sound effects.** There is no `src/audio` module and no
  audio file in the repository.
- **No scraped data tables.** Vehicle values are hand-entered from the sources listed in
  `VEHICLE_DATA_SOURCES.md`; the profile files are the record.
- **No logos or brand marks.** Car names appear as text only (see §6).

Screenshots in `docs/visual-qa/dev/` are captures of this project's own build.

## 6. Trademarks and name clearance — not done

The game refers to real vehicles by name: **Saipa Pride 131**, **Toyota Corolla E210**,
**BMW 320i G20**. These names are used descriptively to identify the vehicles being
simulated. No manufacturer logos, badges, grille roundels, wordmarks or trade dress are
modelled or rendered.

**No trademark clearance, licensing agreement, or legal review has been performed.** Using
manufacturer and model names in a distributed game may require permission in some
jurisdictions, and some manufacturers treat vehicle simulation mods differently from
commercial titles. Before any store release:

1. Obtain legal advice on nominative fair use for each mark in the target markets.
2. Decide between licensed names, generic names, or a disclaimer screen.
3. If names change, update `src/vehicles/profiles/*.ts` (`make`, `model`, `nameEn`,
   `nameFa`), `GDD.md`, `VEHICLE_DATA_SOURCES.md`, and the generated GLB material names.

The Persian place names on generated signs (تهران، چالوس) and the generic speed-control
wording (کنترل سرعت) are drawn as original artwork, not reproductions of official signage.

## 7. Adding an asset — checklist

1. Prefer `tools/assetgen`; if a generator cannot produce it, document why.
2. Record: file path, author/source URL, licence identifier, and the licence file path.
3. Reject anything without a licence that permits redistribution in a closed-source app.
4. Keep the licence text in the repository, not only in a URL.
5. Update this file and `ART_BIBLE.md` (if it changes the visual language) in the same
   commit.
